ERDI TECH/Open tools/UART decoder

LiDAR / laser rangefinder UART decoder

Paste a hex dump or connect a module over WebSerial (Chrome / Edge). The page finds the protocol and baud rate, decodes every frame and flags checksum errors. Everything runs in your browser; nothing is uploaded.

Each profile is built from the vendor's public manual; sources and frame tables are in PROTOCOLS.md. Same bytes can mean different units on different models (an ERDI 5C 02 11 EC is 43.54 m on an H-series module and 4.354 m on a VB module), so confirm the model before trusting the number.

Open source (MIT): github.com/ErdiTech/lrf-uart-protocol-decoder · Python CLI: pip install lrf-uart-decoder · Maintained by ERDI TECH LTD (erdilrf.com), makers of 905 / 1535 nm laser rangefinder modules. Found a module this page cannot read? Open an issue with a hex capture and its manual.
